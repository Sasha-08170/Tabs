# Вкладки с анимацией скольжения 

Компонент вкладок с плавным переходом контента и индикатором под активной кнопкой.
Современный дизайн, мягкие тени, адаптивность и структура по методологии БЭМ.
Подходит для лендингов, интерфейсов и панелей управления.
